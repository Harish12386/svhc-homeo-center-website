SRI VENKATESHWARA HOMEO CENTER — PROFESSIONAL BILINGUAL WEBSITE

Included:
- index.html — website structure and content
- style.css — premium responsive design and decorative product illustrations

PREVIEW LOCALLY:
1. Extract this ZIP.
2. Keep all files together in the same folder.
3. Double-click index.html to open it in Chrome.
4. Internet is only needed for the optional Google Fonts; the site itself is static.

WHAT'S INCLUDED:
- Home, Products, Services, About and Contact sections
- Homeopathic Medicines and Biochemic Salts product categories
- English and Kannada text switch
- Responsive mobile navigation
- Google Maps link supplied for the store
- WhatsApp button placeholder (does not send a message until a real number is configured)
- Logo intentionally not added yet

BEFORE PUBLISHING:
- Public address, phone number and opening hours have been added based on the details supplied by the store owner. Recheck them before publishing.
- Add only approved, real store photos and confirmed details.
- The phone number is clickable for calls. The WhatsApp button remains a placeholder until the store confirms that this number is also its WhatsApp number.
- Check every Kannada translation and all contact information before public launch.
- Do not upload private pharmacy software, databases, backups, passwords, stock exports, or patient/customer information.

FREE HOSTING:
Upload index.html, style.css, and script.js to the root of a GitHub repository. In repository Settings > Pages, choose Deploy from a branch, select main and /(root), then Save.


BRANDED WEBSITE LINK:
- GitHub Pages URLs include the GitHub account username. To get a pharmacy-branded URL without a personal username, deploy this same static site to a free hosting provider that offers a customizable free subdomain (for example, Netlify). Choose a name such as svhc-homeo-center if available; availability is not guaranteed. A custom .com domain generally costs money.
- The website's brand and page title are already pharmacy-focused; changing the hosting URL is a separate step.
